# 工作区使用说明

首次连接服务器与添加仓库见[快速上手](../README.md#快速上手)。这里说明现有工作区的操作方式和边界。

> **版本范围（2026-09-29）：** 本文按 [v0.5.0](https://github.com/ShaoClean/Alune/releases/tag/v0.5.0)（[`e86dc78`](https://github.com/ShaoClean/Alune/commit/e86dc78d3b675084743f59c940f2ab1aafbe1ad5)）核对。该版本已包含命名访问令牌、批量放弃未暂存更改、代码主题与字体配置，以及网络代理。当前截图见[项目首页](../README.md)。

## 布局与工作区导航

在宽窗口中，改动视图按“标签栏 → 仓库工具条 → 左侧仓库导航／中央 Diff／右侧改动与提交 → 底部状态栏”组织。标签栏切换已打开的仓库；支持拖动标签排序，聚焦标签时按 `Alt+←/→` 也可移动。左侧按连接浏览和搜索仓库；中央阅读选中文件；右侧管理暂存内容与提交。提交历史、分支、储藏、远程和 PR/MR 使用各自的主区域布局；提交历史选中提交后，上方为提交图，下方为文件列表与 Diff。

右键仓库标签可选择“关闭此标签页”“关闭其他标签页”“关闭右侧标签页”或“关闭左侧标签页”；范围按当前标签顺序计算，以右键点击的标签为基准。关闭标签只关闭视图，不删除仓库登记或磁盘目录。

当前开发版会即时保存已打开的仓库标签、顺序和最后激活项。重启桌面应用或重新进入网页根地址时恢复上次工作区；刷新或直接访问某个仓库地址时，以地址中的仓库为当前标签，其余标签保留原顺序。设置页和仓库／连接列表保留最后激活的仓库，关闭全部标签后重开停留在仓库列表。已移除的登记会跳过，SSH 断开或目录暂不可用的仓库仍保留标签；仓库列表读取失败时可重试，不清空保存状态。提交草稿、视图类型、选中文件及滚动位置不随重启恢复。详见 [标签恢复设计与验收](https://github.com/ShaoClean/Alune/wiki/Issue-126)。

底部状态栏左侧显示 Alune／当前仓库名称的按钮是“工作区导航”。点击后可搜索和切换已打开的仓库，并进入“浏览全部仓库”“管理远程连接”“设置”和帮助入口。它不依赖左侧面板是否展开。状态栏还显示当前路径、SSH 连接状态、同步进度与通知；点击右侧连接状态可进入连接管理。

「仓库」和「SSH 连接」页右上角提供 **卡片 / 列表** 切换，首次使用默认显示卡片。列表按列对齐名称、路径或主机、状态和操作，适合浏览较多条目；窄窗口可横向滚动查看所有列。两页分别记住上次选择，在本设备刷新或重启后恢复。仓库搜索、连接筛选和状态信息在切换时保留；长名称、路径与分支可悬停查看完整内容。两种视图都支持原有打开、刷新或测试、删除确认等操作。

同步前确认当前仓库来源、分支与“远程”配置；本地仓库使用本机 Git 认证，SSH 仓库使用远程主机的 Git 认证。强制推送在确认后使用 `--force-with-lease`；“推送标签”使用 `--tags`。首次推送可设置上游。

工具条随窗口宽度收拢但不隐藏入口：小于 1100 CSS px 时拉取／推送主要显示图标；视图标签放不下文字时收为图标，小于 700 时固定显示图标，仍放不下则可横向滚动（触控板或滚轮），选中的视图会自动滚入可见区域。悬停提示保留操作名称。窄窗口选择文件或提交后进入检查器，通过“返回列表”继续操作。

## 提交历史与分支图

“提交历史”以多列提交图展示仓库现有引用可达的提交，包括其他本地分支、远程跟踪分支、标签及游离 HEAD。彩色连线根据真实父提交关系绘制；引用过多时显示数量提示，悬停或打开详情可查看完整名称。浏览历史不会自动获取远端数据。

首屏默认加载 50 条，滚动到列表底部时自动追加后续记录并保留选择与滚动位置，直到历史末尾。浏览期间引用或浅克隆边界变化时，会保留已加载记录并提示刷新；失败可重试。浅克隆仅展示本地已获取的历史。

选中提交后，上方保留提交图，下方展示文件变更与 Diff，可拖动分隔线调整高度。合并提交默认对比第一父提交。窄窗口进入详情后，通过“返回列表”恢复浏览位置。设计、截图和验证结果见 [Issue #36 验收](https://github.com/ShaoClean/Alune/wiki/Issue-36-Validation)。

## PR / MR 协作状态

工具条“PR/MR”读取所选远端仓库**收到的**合并请求，覆盖该仓库的全部目标分支。默认选择可识别的 `origin`，没有时选择可用远端；多远端仓库可在下拉框中切换，使用各远端的 fetch 地址，push 地址不参与选择。Fork 仓库若要查看上游收到的请求，请选择 `upstream` 等对应远端。

默认展示“开放中”（包括草稿），也可切换“全部状态”查看开放、关闭和已合并的记录；每页 30 条，按最近更新时间倒序，使用“上一页／下一页”翻页。“刷新”及工具条“刷新仓库”重新读取远端配置和当前页。标题、编号、作者、来源与目标分支、草稿标记和更新时间在列表中展示，点击标题在 Alune 内打开详情，独立的外链图标仍可在系统浏览器打开。没有自动轮询；分页过程中若远端有更新，记录顺序可能变化，可返回第一页刷新。

详情包含“概览”“文件变动”“评论与讨论”：概览展示描述与基本信息；文件变动按页加载，可切换文件并阅读带新旧行号的 Diff；讨论展示作者、时间、回复、Review 记录，以及代码评论的文件和行号上下文。GitLab 保留讨论串及已解决状态；GitHub 的代码回复跨页加载后归入同一讨论串，旧版本行评论会标注。点击“加载更多”读取后续文件或讨论。

“返回列表”保留当前远端、状态筛选和页码；详情顶部可切换当前列表页中的条目，或“刷新详情”重新读取当前页签。详情各部分独立展示加载、空内容及错误状态，失败可重试。二进制、过大、平台省略或截断的 Diff 会提示使用浏览器查看；GitHub API 最多提供 3000 个文件，较旧的 GitLab 会回退到兼容接口。Markdown 描述和评论支持常用格式，远端图片显示替代文字，原始 HTML 不执行。

支持范围与认证：

| 平台   | 范围                                                                   | 私有仓库认证                                                                                             |
| ------ | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| GitHub | `github.com`；HTTPS、SSH、SCP 远端地址                                 | 细粒度令牌需目标仓库的 **Pull requests: Read** 权限；经典令牌需 `repo` 权限。组织仓库可能需要 SSO 授权。 |
| GitLab | `gitlab.com` 自动识别；自建实例需在“托管平台”选择 GitLab，支持多级群组 | 有项目访问权且包含 `read_api` 或 `api` 权限的个人、项目或群组访问令牌。                                  |

公开仓库可选择“不使用令牌”匿名读取。在“设置 → 应用 → 访问令牌”添加名称和值；返回仓库 PR/MR 页，搜索并选择名称，确认显示的主机与项目后点击“应用到此仓库”。从仓库进入管理页时，新增表单提供“保存并返回仓库”，返回后还需明确应用。自建 GitLab 首次选择的平台随关联保存。关联按仓库与远端独立保存，切换视图、仓库、远端和重启后恢复，没有自动用于所有仓库的默认令牌。

首次应用会把令牌限定到该平台和 HTTPS 主机（含端口）。其他主机的令牌不可选择；检测到项目、主机、端口或平台变化时停止使用旧关联，要求重新确认，即使地址随后恢复也不会自动启用。改名保留关联；更换值后新请求使用新值。删除前展示受影响的仓库远端，确认后删除凭据并清除引用，不会在 GitHub / GitLab 撤销令牌。选择“不使用令牌”并应用只解除当前远端的关联。

展开“仅本次输入”仍可临时认证；临时值只保留在当前视图内存中，切换远端、仓库、视图或重载后清除，不改变已保存的选择。加密存储不可用时可使用匿名读取或临时输入；无法解密的已存凭据可在设置中更换值。401 提示检查令牌，403 提示检查当前项目权限，404 表示项目不存在或不可见，网络、限流错误保留选择供重试。Alune 不读取 SSH 服务器上的 Git 凭据，也不复用 AI 密钥。

从本机仓库或通过 SSH 读取仓库远端配置后，托管平台 API **从运行 Alune 的本机访问**。自建 GitLab 需要本机可达、证书受信任的 HTTPS 实例，并部署在域名根路径；HTTPS 远端中的自定义端口会保留，SSH 端口不会用作 API 端口。暂不支持 HTTP 实例、路径前缀部署、SSH 主机别名或 GitHub Enterprise，必要时将 fetch 地址配置为真实 HTTPS 地址。

空列表、没有配置远端、不支持的地址，以及权限、限流、超时和网络错误分别展示；失败可重试，刷新失败时仍保留上次列表并注明。查询超时为 20 秒，平台响应上限为 2 MiB。本视图仅提供阅读，不提供发表评论、回复、发起 Review、批准、合并、关闭或检出操作。方案和验收见 [Issue #98](https://github.com/ShaoClean/Alune/wiki/Issue-98) 、[命名令牌设计 #107](https://github.com/ShaoClean/Alune/wiki/Issue-107) 与[应用内详情 #122](https://github.com/ShaoClean/Alune/wiki/Issue-122)。

## Worktree 与独立标签

仓库工具条分支旁的 **Worktrees** 图标（悬停提示“查看关联 Worktrees”）列出关联工作区的路径、分支或游离 HEAD。选择其中的工作区后，会在独立标签页打开完整仓库页面，并自动加入当前连接下的仓库列表；重复打开会切换到已有标签。各工作区的状态、Diff、提交草稿和 Git 操作使用各自目录，关闭标签不会移除登记或删除远端目录。列表支持刷新，目录失效或读取失败时会显示错误并允许重试。本地仓库还可创建和删除 Worktree，SSH 仓库继续支持发现与打开。设计与验证结果见 [Issue #29](https://github.com/ShaoClean/Alune/wiki/Issue-29)。

## 浏览仓库文件

工具条“文件”以只读方式浏览当前工作区（包括未跟踪文件，不显示 `.git` 目录）。目录树按需加载：只有展开的文件夹才会读取，单个目录最多列出 5,000 项，超出时提示总数。某个目录读取失败只在该目录下显示错误和“重试”，不影响其他目录；切换视图后返回会保留展开状态与选中文件，工具条“刷新仓库”只重新读取当前可见的目录和文件。目录树支持方向键、Home／End、Enter 与首字母快速定位，分隔线可拖动调宽，窗口过窄时改为上下排列。

- **文本**：显示路径、行号、语言、编码、换行符与大小，常见语言带语法高亮。支持 UTF-8 与带 BOM 的 UTF-16，上限 1 MiB；内容超过 256K 个字符时关闭语法高亮以保持流畅。
- **Markdown**：`.md`（不区分大小写）默认打开 Preview，可在右上角切换「源码 / Preview」，当前仓库会话内记住选择。支持常用 Markdown 和 GFM 表格、删除线、只读任务列表；超过 256 Ki 字符时提示切换源码查看完整内容。刷新仓库会重新读取文档和图片，本地与 SSH 仓库使用同一规则。
- **图片**：PNG、JPEG、GIF、WebP 沿用图片 Diff 的预览样式，显示格式、尺寸与大小，上限 5 MiB。
- **其他情况**：二进制文件、超出上限、GBK 等不支持的编码、无读取权限、文件已被删除时分别说明原因，可重试。符号链接显示指向目标但不跟随；嵌套仓库或子模块不进入。

文件浏览不提供编辑、保存、重命名、新建、删除或上传，也不做全文搜索。

Markdown 的相对链接与图片以当前文档所在目录为基准，以 `/` 开头的路径以仓库根目录为基准；路径中的查询参数不参与文件定位，中文、空格等可用 URL 编码。仓库内链接在文件视图中打开，`#标题锚点` 在文档内跳转。仓库图片通过只读文件接口读取，支持上述图片格式和大小限制；越界路径、`.git`、符号链接及不支持的图片会提示原因。HTTP(S) 链接在外部浏览器或新标签中打开，外部图片需点击「加载外部图片」才会请求。原始 HTML、脚本及其他协议不会执行，不支持 MDX、Mermaid 或数学公式扩展。

## 文件差异

新建文件无需暂存即可查看相对空版本的差异，支持统一、分栏及窗口内全屏查看。暂存后再次编辑的文件会同时出现在“已暂存”和“未暂存”分组，分别显示暂存内容与后续工作区改动；没有首次提交的仓库也可暂存、取消暂存和预览。改动文件列表采用单行布局并显示文件类型图标，窄栏会隐藏路径以保留文件名。

空文件显示“新增空文件”，二进制文件和无法读取的文件有明确反馈。预览支持 UTF-8 文本，新增文件/暂存内容及差异输出限制为 1 MiB，差异补丁最多 10,000 行；超限时显示提示。预览不写入文件或暂存区。验证范围和结果见 [新增文件差异预览验收](https://github.com/ShaoClean/Alune/wiki/Issue-18-Validation)。

PNG、JPEG、GIF、WebP 图片直接显示预览而不是二进制提示：新增显示变更后版本，删除显示变更前版本，修改并排显示“变更前 / 变更后”，并标注格式、像素尺寸和文件大小。图片按宽高比自适应缩放，透明区域以棋盘格背景显示。提交历史与工作区改动使用同一套预览：工作区比较暂存区与磁盘内容，已暂存比较 HEAD 与暂存区，提交比较父提交与该提交。单张图片上限为 5 MiB，超限、无法解码、缺少读取权限或其他格式仍按二进制文件提示处理，不影响同一 Diff 中的其他内容。预览只读取内容，不写入文件或暂存区。

Diff 工具栏的“全屏查看差异”将当前差异铺满应用窗口，网页端铺满浏览器内容区域，保留视图切换和关闭差异入口。再次点击收起图标或按 `Esc` 退出；该操作不改变系统窗口状态，也不修改两侧面板的显隐偏好。全屏前后使用同一份内容，退出时恢复进入前的滚动位置；若全屏期间切换了文件或统一 / 分栏模式，则按新内容从顶部阅读。图片保持比例、透明背景和尺寸标注。

## 目录类型的改动（开发分支）

以下行为适用于 Issue #120 修复后的源码，v0.5.0 安装包尚不包含。普通目录继续按内部文件显示；嵌套仓库、Worktree 和子模块使用仓库图标与类型标识，目录名称不会因路径末尾的 `/` 留空。

点击嵌套仓库或 Worktree 条目可查看说明，并打开对应仓库；它们不提供普通文件的暂存或删除按钮。子模块可查看提交指针差异并暂存指针变化，内部文件改动需进入子模块处理。移除 Worktree 使用原有的 Worktree 管理入口。

“全部暂存”会先列出跳过的目录或仅有内部改动的子模块，再暂存其余可处理改动。“放弃所有更改”的确认窗口同样列出跳过项；目录、嵌套仓库及子模块不会被递归删除或恢复，不会阻断其余普通文件的处理。

未跟踪目录的“本地忽略”会追加一条精确目录规则到仓库的 Git `info/exclude`，保留磁盘文件，不修改 `.gitignore`。该规则由同一仓库的 Worktree 共享；删除对应规则即可恢复显示。目录路径包含换行时不提供此入口。设计与验收截图见 [Issue #120](https://github.com/ShaoClean/Alune/wiki/Issue-120)。

## 批量放弃未暂存更改

“改动”面板的“未暂存”分组右侧提供“放弃所有更改”。点击后先核验并显示仓库名称、路径及影响的文件数量，确认后才执行。操作覆盖整个当前仓库 / Worktree，不受文件列表筛选影响，其他仓库和 Worktree 不受影响。

默认只将已跟踪文件的未暂存内容恢复到暂存区版本，保留全部已暂存内容，包括已暂存的新文件。未跟踪文件默认保留；勾选“同时删除 … 个未跟踪文件”后，确认按钮变为“放弃全部并删除”。这些文件会直接删除，不进入回收站，Git 无法恢复；忽略文件不受影响。

执行前请核对范围，放弃的未暂存内容不可撤销。若操作未全部完成或连接中断，按提示检查刷新后的实际状态，再重新读取并确认。

## 布局与快捷键

顶栏按钮可分别隐藏或重新打开两侧面板。Diff 工具栏的“专注阅读差异”（准星图标）一次隐藏两侧，独立于“全屏查看差异”（展开图标）。

两侧面板支持拖动调宽，也可在“设置 → 布局”调整显隐、宽度、默认 Diff 模式或恢复默认。分隔线支持方向键、Shift 加速和 Home / End；分栏 Diff 的长行自动折行。布局偏好在本机保存，恢复默认不会清除工作区树的展开与排序设置。

| 快捷键             | 操作                       |
| ------------------ | -------------------------- |
| `Cmd/Ctrl+B`       | 切换左侧仓库导航。         |
| `Cmd/Ctrl+Shift+B` | 切换右侧改动面板。         |
| `Cmd/Ctrl+\`       | 保留的左侧面板切换快捷键。 |
| `Cmd/Ctrl+,`       | 打开设置中心。             |
| `Esc`              | 退出全屏 Diff。            |
| `Alt+←/→`          | 移动聚焦的仓库标签。       |

提交摘要和描述在本次页面会话内按仓库保留；切换标签或进入设置再返回不会清空，刷新页面会清空草稿。历史布局记录见 [Issue #31 验收](https://github.com/ShaoClean/Alune/wiki/Issue-31-Validation)；当前导航与截图以本文所列基线为准。

## AI 提交与设置

在“改动”中选择文件查看差异，暂存需要提交的内容，填写摘要与可选描述后点击“提交已暂存内容”。未暂存改动不会包含在这次提交中。

从底部“工作区导航 → 设置”或 `Cmd/Ctrl+,` 打开设置中心。左侧分为 **AI**（AI 服务商、提交生成）和 **应用**（访问令牌、布局、外观、网络代理、版本更新）两组，共七个分类。点击“返回工作区”恢复原仓库、面板和提交草稿。窄窗口通过“设置分类”和服务商列表逐级进入详情。

AI 先在“AI 服务商”保存服务配置并启用模型，再在“提交生成”选择默认模型。摘要输入框右侧的星光按钮触发生成，悬停提示“生成提交信息”；描述框下方的辅助栏显示当前默认模型与生成范围。点击模型直接进入“提交生成”设置，不在提交区原地切换模型。

AI 仅分析已暂存改动，默认使用简体中文 Conventional Commits，生成可编辑的摘要和描述，支持取消、重试与撤销。检查结果后仍由用户主动提交。模型服务会收到已暂存差异，服务商、模型、API Key 保护及详细数据范围见 [AI 设置说明](ai-settings.md)。桌面更新条件见[桌面端说明](desktop.md)。

## 外观与动态效果

通过底部工作区导航中的“设置”或 `Cmd/Ctrl+,` 打开设置中心，选择“外观”。主题可选跟随系统、浅色和深色，新装默认跟随系统。显式选择浅色或深色后，不再随系统主题变化；选回“跟随系统”会立即应用系统外观。

“减少动态效果”关闭非必要的过渡和循环动画，连接、提交与同步的状态文字和实际结果继续显示。系统已开启减少动态效果时，应用始终遵循该设置。

外观修改立即生效并保存于此设备。桌面端与布局偏好一起存储在稳定的数据目录中，重启和动态 HTTP 端口变化不会丢失。切换主题不会重置面板宽度、折叠状态、仓库排序、Diff 模式或正在编辑的提交草稿。颜色规范及验收范围见 [Issue #86 Wiki](https://github.com/ShaoClean/Alune/wiki/Issue-86)。

### 代码主题与字体（v0.5.0 起）

“设置 → 外观 → 代码阅读”可调整文件预览的代码主题、字体和字号，并用 TypeScript、Python、JSON 示例即时预览。本地与 SSH 仓库共用这些设置；Diff 保留原有配色和字体。

内置 Catppuccin Latte（浅色）、Frappé、Macchiato、Mocha（深色）。浅色默认 Latte，深色默认 Mocha。主题列表禁用与当前 Alune 外观不匹配的项；浅深色分别记住选择，跟随系统时按系统实际外观切换。选择或安装代码主题不会改变 Alune 外观。

代码字体填写一个本机安装的字体名称（如 `JetBrains Mono`），字号为 10–32px。不可用字体自动回退到系统等宽字体；默认 `SFMono-Regular`、13px。“恢复代码默认设置”重置两种外观的主题与字体，保留已导入主题。

“导入主题 JSON”支持最多 1 MB 的独立 VS Code Color Theme JSON / JSONC，允许注释和尾随逗号。文件需包含 `type: "light"` 或 `type: "dark"` 及可映射的 `tokenColors` 语法颜色；主题名称使用 `name`，缺省取文件名。安装后显示名称、文件来源、类型；不会自动启用，可在对应外观下选择或随时卸载。本设备最多保存 32 个自定义主题。当前主题被卸载、损坏、缺失或类型不匹配时，回退到对应 Catppuccin 默认值并显示提示。

兼容范围：读取 `editor.background`、`editor.foreground`、`editorGutter.background`、`editorLineNumber.foreground`、`editor.selectionBackground`，颜色支持 `#RGB`、`#RGBA`、`#RRGGBB`、`#RRGGBBAA`。`tokenColors` 的字符串、逗号分隔或数组 scope 按最长已知前缀映射到 Prism 的注释、关键字、字符串、数字、常量、函数、类型、标签、属性、正则、变量、标点、运算符、增删类别，并支持粗体、斜体、下划线和删除线。类别内后出现的同优先级规则覆盖前者，语言后缀合并到通用类别；缺失颜色沿用默认主题。不会执行 TextMate 上下文选择器或语义高亮规则，预览可能与 VS Code 有差异。暂不支持 `.vsix`、主题市场和 `include` 外部依赖。

Web 使用 localStorage；桌面与其他设备偏好一起写入稳定的 `workspace.json`，跨启动端口恢复。未知语言保持纯文本，超过 256 Ki 字符的内容关闭高亮，原有文件读取大小上限仍然有效。高亮模块加载失败时保留可选择复制的文本，并显示提示。

## 网络代理

在“设置 → 应用 → 网络代理”配置 HTTP、HTTPS 或 SOCKS5 代理，修改后点击“保存配置”。AI 请求、版本更新、SSH 连接和 SSH 仓库的远端 Git 网络操作使用此配置；已有 SSH 连接显示“重新连接后生效”，需点击“重新连接并应用”。页面可分别测试 HTTP、SSH 和远端 Git，SSH 已连接不代表远端 Git 一定可用。

本地仓库网络操作与 PR/MR 查询沿用原有配置，不在此设置的覆盖范围内。服务器转发条件、认证存储、连接测试和各类请求的生效时机见[网络代理说明](network-proxy.md)。

## 本地 Git 工作区

“仓库 → 打开本地仓库”支持系统目录选择器（桌面端）或完整路径输入。可选择仓库子目录，Alune 会定位实际根目录；重复打开会复用登记。仓库按“本机”和 SSH 连接分别分组，标签和状态栏显示来源，底栏保留完整路径。关闭标签只关闭视图；移除仓库登记保留磁盘文件。

本机须安装 Git，并确保它在启动 Alune 时的 PATH 中。本地操作复用本机 Git 配置、凭据助手、SSH Agent 和 known_hosts；应用不会把 SSH 连接列表中的密码或私钥用于本地同步。需要交互认证时，请先在系统终端完成认证，再回到 Alune 重试。

没有首次提交时可以暂存文件并提交；未配置作者时，工作区提示“设置作者”，仅写入此仓库的配置。没有远程时仍可本地工作，点“添加远程”补充地址。首次推送会要求选择远程和上游分支。浅克隆可从提示栏获取完整历史。

分支视图支持创建、切换、重命名、安全删除和合并。冲突文件标记为 U；在编辑器中解决冲突后刷新、暂存并提交。Stash 支持查看差异、包含未跟踪文件、应用、弹出和删除；应用失败时保留错误和实际仓库状态。

Worktree 菜单可创建新分支和仓库外的新目录，并在独立标签打开。删除目录需要勾选确认，当前、锁定、失效以及含改动、未跟踪或忽略文件的 Worktree 会被保护。删除目录会保留分支。

耗时 Git 写操作显示执行状态与耗时，可以取消。取消不回滚已经完成的步骤，刷新后确认工作区；同一仓库不会同时启动两个写操作。强制推送使用租约保护并要求二次确认。
