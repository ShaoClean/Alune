# 常规成功反馈盘点（#151）

关联：[Issue #151](https://github.com/ShaoClean/Alune/issues/151)。

## 处理原则

移除业务触发点，而不是禁用共享反馈系统。结果已经由列表、表单或仓库状态呈现的常规完成事件，不再发布弹窗，也不替换为逐次 toast、通知或横条。错误、部分完成、能力限制和执行前确认保留。

## 全应用盘点

| 场景 | 处理结果 | 成功后的界面依据 |
| --- | --- | --- |
| 单文件/全部暂存、取消暂存 | 移除完成提示 | 强制读取新状态，更新分组、计数及 Diff 修订号 |
| 提交、丢弃文件改动、忽略目录 | 移除完成提示 | 原有草稿清理、状态与历史刷新保持不变 |
| 放弃所有改动 | 全部成功静默；部分完成仍报告恢复、删除、剩余及未知数量 | 原有预览/确认与刷新保留 |
| 删除新文件、文件菜单删除/重命名 | 移除完成提示 | 原有关闭、树/状态/预览刷新保留 |
| 复制绝对/相对路径 | 移除完成提示 | 剪贴板写入不变，失败仍报告 |
| 分支创建/切换/删除/重命名/合并 | 移除完成提示 | 原有分支、历史与仓库刷新保留；命名冲突处理保留 |
| 储藏创建/应用/弹出/删除 | 移除完成提示 | 原有储藏列表与状态刷新保留 |
| 添加远程、保存仓库作者 | 移除完成提示 | 远程列表/仓库配置刷新保留 |
| 获取、拉取、推送 | 移除完成提示 | 原有状态、分支、历史刷新及错误/冲突反馈保留 |
| 添加/移除连接和仓库（含导航入口） | 移除完成提示 | 原有列表更新、表单关闭、导航及连接状态保留 |
| SSH 连接测试 | 不再另弹“连接成功” | 连接在线/失败状态仍在列表展示 |
| PR/MR 评论、合并、关闭 | 移除成功状态与反馈组件 | 评论、草稿和详情刷新保持不变；权限与确认保留 |
| AI 生成提交信息 | 成功填入草稿后静默 | 草稿与撤销入口仍可用；失败/上下文变更提示保留 |
| AI 提供商保存、模型列表刷新、取消请求 | 移除常规完成提示 | 已保存配置与模型列表更新；显式连接测试的诊断结果保留 |
| 提交生成设置保存 | 仅失败反馈 | 接受并显示服务端保存后的设置 |
| 代理设置保存 | 移除完成提示 | 已保存状态、连接列表与重连入口保留；HTTP/SSH/Git 显式测试结果保留 |
| 代码主题导入 | 普通成功静默；忽略不支持的规则时改为警告 | 主题列表更新，失败仍报告 |
| 工作树、标签、平台令牌、布局/外观、终端等其他入口 | 未发现需要移除的常规成功弹窗 | 不新增提示，不改变原交互 |
| 桌面更新 | 保留版本可用、待重启安装及错误信息 | 这些结果要求用户后续处理，不属于常规完成确认 |

状态徽标、已保存状态、诊断结果和测试夹具中的 success 类型不是业务完成弹窗。共享反馈系统的 success 能力及四类消息测试继续保留。

## 连续操作稳定性

暂存/取消暂存开始前记录焦点与滚动位置。原按钮移除时将焦点转到同文件的反向操作；批量按钮移除时转到反向批量操作；无目标时回到文件筛选框。恢复使用 preventScroll，不抢回用户在请求期间主动移走的焦点。提交摘要和描述忙碌时改为只读，防止禁用控件导致焦点和光标丢失。

## 验证记录与边界

- Web 单元/组件/状态回归：223 项通过（含新增的成功反馈守卫、部分完成结果和更新后的分支切换断言）。
- Web 生产构建及共享 UI 类型检查通过；新增交互夹具额外纳入 TypeScript 检查通过。
- 桌面单元测试：45 项通过。
- Chromium 与真实 Electron 渲染器共用交互回归：分别以 local/ssh 来源运行。每组 13 次成功操作，覆盖连续单文件、全部暂存/取消暂存、分组/计数/刷新修订、零反馈队列、草稿/筛选/滚动/光标稳定、请求期间主动移动焦点、失败弹窗和丢弃前确认。
- 公共反馈在 Chromium 中通过；Electron 完整反馈与通知中心曾整轮通过，但三次完整运行中另两次在公共反馈的文件预览场景等待超时，最终整轮结果仍为失败。新增静默成功场景三次均通过。该间歇性问题尚未定位；没有修改公共反馈实现或放宽断言来掩盖失败。
- 交互夹具只替换 API 响应，使用真实组件、反馈 store 与仓库刷新 store。local/ssh 是来源参数覆盖，**不是实际 SSH 连接验收**。本次没有访问真实远端仓库，也没有逐项执行表中所有写操作。
- Diff 的验证由交互回归中的失效修订号和既有状态/Diff 回归共同覆盖；新增夹具不渲染完整仓库 Diff 页面。真实本地/SSH 仓库的端到端 Git/Diff 验收仍需在受控测试仓库完成。

## 复现

```bash
npm test -w web
npm run build -w web
npm run check -w @alune/ui
npm run test:unit -w desktop
```

启动隔离的前端测试页后，桌面共享脚本会依次运行静默成功、公共反馈、通知中心检查：

```bash
npm run dev -w web -- --host 127.0.0.1 --port 5188 --strictPort
node apps/desktop/scripts/test-feedback.mjs
```

浏览器自动化可调用 `runQuietSuccessChecks(page)`，默认连接同一端口；无需真实 Git 仓库或 SSH 凭据。
